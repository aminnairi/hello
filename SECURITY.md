# Security Policy

## Supported Versions

All versions marked with a green check mark are supported by backport security patches.

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

Report any vulnerabilities by [openning a new issue](./issues) and explaining the details of your findings.
